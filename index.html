Schemas & contracts

Protobuf schemas carry field types, validation rules, UI labels, and extraction guidance. Buf manages schema tooling; code generation produces Go/TypeScript bindings, JSON Schema, and Pydantic models. This keeps applications working from shared definitions.

Backend & workflows

Python/FastAPI services handle preprocessing, call submission, summaries, and evaluations. The case-management backend is written in Go, with HTTP/gRPC APIs and Temporal workflows and activities. Stedi integrates payer search and eligibility checks.

Go · FastAPI · gRPC · Temporal · Stedi

Web applications

The surrounding dashboard stack uses React and TypeScript, TanStack Query for server data, React Hook Form and Zod for forms and validation, and Radix UI components. These interfaces consume shared contracts and agent outputs.

Configuration & access

The voice application uses Unleash feature flags; case-processing services also use Compass ConfigStore for runtime configuration. The surrounding platform includes Auth0 authentication, Casbin role-based authorization, and Vault-managed secrets.

Unleash · ConfigStore · Auth0 · Casbin · HashiCorp Vault

Healthcare & data handling

My workflows cover insurance eligibility, medical and pharmacy benefits verification, prior authorization status, and coordination of benefits. That means handling plan-specific questions, coverage details, and information confirmed by payer representatives.

I have implemented PHI-redacted transcript access for audit tooling. The engineering work is to keep debugging useful while limiting exposure of protected health information, alongside the platform’s authentication, authorization, and secrets-management controls.
