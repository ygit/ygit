02 / Structured extraction · Grounding · Python / TypeScript

Reliable extraction and decision systems ↗

Make the saved record preserve what was actually confirmed—and keep its meaning stable as different services process it.

My contribution
I added route-aware field cleanup, corrected unsupported coverage inference, and maintained equivalent decision behavior across the live agent and Python/TypeScript engines.
Key decision
Validate relationships and evidence as well as field types; test the same saved output through repeated processing.
Evidence
In a historical offline replay of 1,346 calls, the extraction correction cleared 163 copied values across 33 calls, with no disposition-code changes in that sample.

03 / Replay · Prompt regressions · Ablation

Agent evaluation tooling ↗

Turn an observed agent failure into a reproducible test, then establish which changes are necessary to fix it.

My contribution
I built local call-replay tooling and strengthened regression coverage across rendered prompts, model responses, extraction lag, resumed context, and grading.
Key decision
Require useful progress and the triggering state; test each layer separately and remove individual changes to check their necessity.
Evidence
Selected historical prompt replays recorded 0/240 inappropriate appeal asks on the fix versus 32/120 on the baseline. These are test runs, not a production success rate.
